## งานที่ทำ
| ไฟล์ | เนื้อหา |
|---|---|
| `lib/pending-payment.ts` 🆕 | cache `expires_at` จาก checkout ลง sessionStorage (payment API ไม่มี field นี้) |
| `lib/booking-presentation.ts` 🆕 | label/สีสถานะ + type→kind รูป |
| `app/(mobile-tourist)/cart/page.tsx` 🆕 | กลุ่มตามหมวด, ± จำนวน, ลบ, ยอดรวม, ปุ่มไป checkout |
| `app/(mobile-tourist)/checkout/page.tsx` 🆕 | สรุปรายการ, subtotal/fee/net, ยืนยัน → checkout API, เก็บ expires_at, ล้าง cart, ไปหน้า payment |
| `app/(mobile-tourist)/checkout/payment/[paymentId]/page.tsx` 🆕 | จำนวนเงิน, countdown 15 นาที, payee/placeholder, อัปสลิป (multipart), badge รอตรวจ, ปุ่มไป my-bookings |

## WHY สำคัญ
1. ยอดใน cart/checkout = **estimate**; ยอดจริงจาก response ของ checkout (เก็บ `net_amount`) — UI บอกชัด
2. `expires_at` อยู่ที่ booking ไม่ใช่ payment → แคชใน sessionStorage ตอนผ่าน /checkout (ปิดแท็บแล้วหาย ไม่ค้างเครื่อง)
3. Slip upload เก็บ PENDING_CHECK เท่านั้น → ข้อความ "อัปโหลดแล้ว รอเจ้าหน้าที่" ไม่ใช่ "ชำระสำเร็จ"
4. หน้า payment poll ทุก 15 วิ ให้สถานะเปลี่ยนเองเมื่อ staff verify แล้ว
5. payee ว่าง → แสดง placeholder ตาม backend ที่ยังไม่ได้ config
