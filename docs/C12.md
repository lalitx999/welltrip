## WHY / ข้อจำกัด (สำคัญ)
1. Backend ยังไม่มี **vendor-scoped GET** → หน้า portal แสดงรายการ ACTIVE จาก public API + แจ้ง note ชัดเจน; ของคนอื่นแก้ไม่ได้เพราะ backend ตอบ 403 (โชว์ message)
2. Backend ยังไม่มี **PATCH** → restaurant = แสดงสถานะอย่างเดียว (ตามที่ตกลง Q4)
3. Role gate ตามที่ตกลง: TOURIST redirect /home; COMMUNITY_ADMIN เห็น "no access"; SUPER_ADMIN ผ่านทุกหมวด (backend อนุญาต)
4. ยังไม่มีหน้า login แยก vendor → user เข้า `/portal` หลัง login ด้วย role นั้น ๆ (login flow เดิม redirect /home ทุก role — อาจเพิ่ม role-routing ภายหลัง ถ้าต้องการ)
