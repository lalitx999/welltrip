> **ประเภทเอกสาร:** สรุปงานรายรอบ (ONE MODULE = ONE MD)
> **อัปเดต:** 2026-09-09
> **สถานะ:** ⬜ รอ user review + `npm run typecheck`

## งานที่ทำ
| ไฟล์ | เนื้อหา |
|---|---|
| `app/(mobile-tourist)/my-bookings/page.tsx` 🆕 | tabs active/completed/cancelled (map 1:1 กับ backend), การ์ดคำสั่งซื้อ + status badge + หมดเวลา |
| `app/(mobile-tourist)/my-bookings/[id]/page.tsx` 🆕 | voucher: code/status, items snapshot + schedule, subtotal/fee/net, payee/placeholder, ปุ่มไปชำระ (ถ้ายังค้าง), สลิป preview |
| `app/(mobile-tourist)/profile/page.tsx` 🆕 | ข้อมูลบัญชี + logout (กัน tab /profile 404) |

## WHY สำคัญ
1. Tab `cancelled` ฝั่ง backend รวม `PAYMENT_EXPIRED` → badge ยังแสดง "หมดเวลาชำระเงิน" แยกจาก "ยกเลิก"
2. รายการ items เป็น **snapshot** (ราคา/ชื่อตอนจอง) = ประวัติถาวร ห้ามแก้ทีหลัง
3. สลิป preview ต้องเรียก `GET /payments/{id}/` เพิ่ม (booking detail มีแค่ payment summary)
4. Profile เป็นหน้าใหม่เบา ๆ ไม่แตะ auth files เดิม

## Known issues
- ถ้า user กดลิงก์ตรงไปหน้า detail ของ order ที่ไม่ใช่ของตัวเอง backend ตอบ 404 (ไม่มี data leak)
- `formatDateText` ใช้ Intl th-TH (อาจแสดงปี พ.ศ.) ตาม locale
