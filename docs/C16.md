# Module: แผนที่ท่องเที่ยวศรีสะเกษแบบอินเทอร์แอคทีฟ & การปรับอัตลักษณ์แบรนด์ (Sisaket Interactive Map & Brand Identity)

## ทำอะไร
- เปลี่ยนโลโก้แบรนด์บน Header Navbar เป็น `/logoWelltrip.jpg` และตั้งค่า Favicon แท็บเบราว์เซอร์รวมถึง PWA Icons เป็น `/logoWelltrip.ico` และ `/logoWelltrip.jpg`
- พัฒนาคอมโพเนนต์แผนที่อินเทอร์แอคทีฟ `SisaketInteractiveMap` วางคั่นระหว่างเมนู 4 หมวดหมู่หลัก กับส่วนแสดงโฮมสเตย์บนหน้าแรก (`/home`)
- ใช้ OpenStreetMap Standard Tile Server (ฟรี 100% ไม่มีลายน้ำ ไม่มี API Key)
- แสดงหมุดสถานที่ท่องเที่ยว โฮมสเตย์ จุดบริการสุขภาพ สวนเกษตร GI และสินค้า OTOP ที่มีพิกัดจริงใน จ.ศรีสะเกษ
- ออกแบบหมุดเป็นแบบ Capsule Badge แสดงป้ายชื่อสถานที่ภาษาไทยบนแผนที่ทันที
- มีตัวกรองหมวดหมู่, การ์ดพรีวิวข้อมูลสถานที่ด้านล่าง, ลิงก์นำทาง Google Maps และระบบป้องกัน Scroll Hijacking บนมือถือ

## ทำไมถึงทำแบบนี้
- **ทำไมเลือก OpenStreetMap แทน Google Maps / CartoDB:**
  - Google Maps ต้องใช้ API Key และเสี่ยงค่าใช้จ่ายส่วนเกิน
  - CartoDB มีการเพิ่มนโยบายบังคับใช้ API Key จนเกิดลายน้ำสีเทา "API KEY REQUIRED"
  - OpenStreetMap Standard Tiles ใช้งานได้ฟรี 100% ไม่มีลายน้ำ และมีความเสถียรสูง
- **ทำไมโหลด Leaflet ผ่าน Dynamic CDN Loader:**
  - เพื่อรองรับ Next.js 16 (Turbopack) และ React 19 โดยไม่มีปัญหา Peer Dependency Conflicts
  - ป้องกันปัญหา `window is not defined` (SSR Error) โดยโหลดเฉพาะในฝั่ง Client
- **ทำไมใช้ Capsule Badge ติดกับหมุด:**
  - ผู้ใช้งานสามารถมองเห็นชื่อสถานที่ได้ทันทีบนแผนที่โดยไม่ต้องคอยกดจิ้มทีละหมุดเพื่อดูว่าคือที่ไหน

## โครงสร้างไฟล์
- `frontend/public/logoWelltrip.ico` และ `logoWelltrip.jpg`: ไฟล์อัตลักษณ์แบรนด์และไอคอน
- `frontend/src/app/layout.tsx`: กำหนด Metadata Icons และ Favicon ของระบบ
- `frontend/src/app/manifest.ts`: กำหนด PWA Icons สำหรับการติดตั้งบนมือถือ
- `frontend/src/components/travel/travel-shell.tsx`: แสดงโลโก้แบรนด์ WellTrip บน Navbar
- `frontend/src/lib/sisaket-map-data.ts`: ชุดข้อมูลพิกัดสถานที่จริงใน จ.ศรีสะเกษ (แหล่งท่องเที่ยว, โฮมสเตย์, สปาสุขภาพ, OTOP)
- `frontend/src/components/travel/SisaketInteractiveMap.tsx`: คอมโพเนนต์แผนที่ Leaflet แบบอินเทอร์แอคทีฟ
- `frontend/src/app/(mobile-tourist)/home/page.tsx`: ติดตั้งคอมโพเนนต์แผนที่บนหน้าแรกด้วย `next/dynamic`

## จุดที่ต้องระวัง
- **การใช้งานบนมือถือ (Touch Gestures):** บนหน้าจอมือถือ ผู้ใช้อาจไถโดนพื้นที่แผนที่ จึงใส่เลเยอร์ "แตะเพื่อเริ่มใช้งานและเลื่อนแผนที่" ไว้ เพื่อไม่ให้รบกวนการ Scroll หน้าจอหลัก
- **พิกัดสถานที่ใหม่ในอนาคต:** เมื่อมีการอนุมัติร้านค้าหรือโฮมสเตย์ใหม่จากระบบหลังบ้าน สามารถเชื่อมโยง API เพื่อนำพิกัดมาแสดงบนแผนที่นี้ได้แบบไดนามิก
