# Module: OTOP Category Compatibility & Media Image Normalization (C20)

## ทำอะไร
- แก้ไขข้อผิดพลาด `"FOOD_BEVERAGE" is not a valid choice.` เมื่อผู้ประกอบการลงทะเบียนสินค้า OTOP ใหม่
- แก้ไขปัญหารูปภาพสินค้า OTOP ขึ้นไอคอน Broken Image (เครื่องหมายคำถาม `?`) บนอุปกรณ์มือถือ (iOS Safari)
- รายละเอียดการปรับปรุง:
  1. **Backend Category Auto-Mapping:**
     - ใน `backend/apps/otop/serializers.py` (`OTOPProductSerializer.to_internal_value`): เพิ่มตัวแปลง Category Alias เชื่อมโยง `"FOOD_BEVERAGE"` ➡️ `"PROCESSED_FOOD"` และ `"HANDICRAFT"` ➡️ `"CRAFT"` อัตโนมัติก่อนส่งเข้าโมเดล
     - ใน `backend/apps/otop/views.py` (`OTOPProductListView.get_queryset`): เพิ่มการแมปชื่อหมวดหมู่ในการกรองค้นหาผ่าน Query Parameters
  2. **Frontend OTOP Registration & Media Upload:**
     - ใน `frontend/src/app/(portal)/portal/otop/page.tsx`:
       - ปรับค่าใน `OTOP_CATEGORIES` ให้ส่ง `PROCESSED_FOOD` และ `CRAFT` ตามข้อกำหนดหลัก
       - ปรับปรุงการอัปโหลดรูปภาพผ่าน `/api/v1/media/upload/` แบบ Async อัตโนมัติ เพื่อให้ได้ URL รูปภาพจริงบนเซิร์ฟเวอร์
       - ปรับเปลี่ยนจากการใช้เบราว์เซอร์ `alert()` มาใช้ `showSuccess()` และ `showError()` ของ SweetAlert2
  3. **Image URL Normalizer & Graceful Fallback:**
     - ใน `frontend/src/lib/images.ts`:
       - พัฒนาฟังก์ชัน `normalizeImageUrl`: ตรวจจับ URL แบบ relative (`/media/...`) หรือ `localhost:8000` และแปลงเป็น URL ของเซิร์ฟเวอร์ Backend จริง (`API_BASE_URL`) เพื่อให้มือถือเข้าถึงไฟล์ได้
     - ใน `frontend/src/app/(mobile-tourist)/otop/page.tsx`:
       - เพิ่ม `onError` ให้กับแท็ก `<img>` ทั้งในหน้า Grid สินค้าและหน้าต่าง Modal เพื่อสลับมาใช้รูปภาพสินค้าศรีสะเกษสำรองทันทีหากเครือข่ายโหลดภาพจริงไม่ติด

## ทำไมถึงทำแบบนี้
- **ทำไมต้องทำ Auto-Mapping ฝั่ง Backend:** เพื่อความทนทานต่อข้อผิดพลาด (Fault Tolerance) และรองรับความเข้ากันได้ย้อนหลัง (Backward Compatibility) หากผู้ใช้เปิดหน้าเว็บจากแคชเก่าที่ยังส่ง `FOOD_BEVERAGE` มา ระบบก็จะแปลงให้โดยไม่ขึ้น Error 400
- **ทำไมต้อง Normalize URL รูปภาพและใส่ `onError`:** ป้องกันภาพ Broken Image ไอคอน `?` บนมือถือ 100% ทำให้ UI สวยงามตามเกณฑ์ Luxury Eco-Tourism เสมอ

## โครงสร้างไฟล์
- `backend/apps/otop/serializers.py`: ตัวแปลง Alias หมวดหมู่สินค้า OTOP
- `backend/apps/otop/views.py`: ตัวกรองหมวดหมู่ OTOP
- `frontend/src/app/(portal)/portal/otop/page.tsx`: ปรับค่าตัวเลือกหมวดหมู่, อัปโหลดมีเดีย และใช้ SweetAlert
- `frontend/src/lib/images.ts`: ตัวแปลงและปรับแต่ง URL รูปภาพ
- `frontend/src/app/(mobile-tourist)/otop/page.tsx`: เพิ่ม Fallback `onError`
