## 1. วัตถุประสงค์ (ทำอะไร & ทำไมถึงทำแบบนี้)

จากการสำรวจระบบจริงร่วมกับข้อสังเกตของผู้ใช้ ได้ทำการปรับปรุงแก้ไขให้ระบบทำงานบนข้อมูลจริงและพร้อมใช้งาน (Production-Ready):
1. **ขจัด Mock Data และเชื่อมข้อมูลจริง:** หน้า Profile ได้รับการลบ Fallback ค่าสมมติทั้งหมด และเชื่อมจำนวนการจองจริงจาก `getMyOrders()` พร้อมสร้างระบบรายการโปรด (Favorites Store) ใช้งานได้จริง
2. **ติดตั้งระบบ PWA (Progressive Web App):** สร้าง Web App Manifest (`app/manifest.ts`), ติดตั้ง Service Worker (`public/sw.js`), จัดเตรียม App Icon ทั้ง SVG และ PNG รวมถึงคอมโพเนนต์ Custom Install Banner สำหรับติดตั้งลงหน้าจอมือถือ
3. **ปรับปรุงระบบ GPS ให้โปร่งใสและมีประโยชน์:** แก้ปัญหาความสับสนที่ผู้ใช้อยู่พัทยาแต่หน้าเว็บขึ้นศรีสะเกษ โดยสร้างโมดูล `lib/geo.ts` (Haversine Formula) คำนวณระยะทางจริงจากพิกัดของผู้ใช้ไปยังศรีสะเกษ และแสดงผลให้ผู้ใช้ทราบอย่างโปร่งใส
4. **ตรวจสอบวงจรร้านค้า (Merchant Lifecycle):** ยืนยันความสมบูรณ์ของระบบสมัครร้านค้า (`/register/merchant`), การอนุมัติของแอดมิน (`/admin/approvals`), และการจัดการสินค้าผ่าน Portal

## 2. สรุปผลการดำเนินงานแยกตาม Stage

### 🟢 Stage 1: ล้าง Mock Data และเชื่อมระบบโปรไฟล์จริง (Profile & Favorites) — [สำเร็จ]
- **`frontend/src/store/favorites-store.ts`:** สร้าง Zustand Store พร้อม LocalStorage Persistence สำหรับบันทึกสถานที่และสินค้าที่ผู้ใช้ถูกใจ
- **`frontend/src/app/(mobile-tourist)/profile/page.tsx`:** 
  - ลบชื่อและเมลสมมติ (`"Tanchonz Wannawongz"`, `"@obsidianzx.m123"`, `"11 ต.ค. 2569"`) ออกทั้งหมด
  - เชื่อมต่อ `getMyOrders()` ดึงจำนวนการจองจริงมาแสดงในการ์ด "การจองของฉัน"
  - เชื่อมจำนวนรายการโปรดจาก `favorites-store` มาแสดงในการ์ด "รายการโปรดที่บันทึกไว้"
- **`frontend/src/app/(mobile-tourist)/recommended/page.tsx`:** เพิ่มแท็บ "รายการโปรดที่บันทึกไว้" แสดงการ์ดที่พัก/สินค้าจริงที่ผู้ใช้กดหัวใจไว้ พร้อมปุ่มลบและลิงก์เปิดดู
- **`frontend/src/app/(mobile-tourist)/hotels/[id]/page.tsx`:** เพิ่มปุ่มหัวใจบันทึกเป็นรายการโปรดที่มุมบนของหน้าจอ

### 🟢 Stage 2: ติดตั้งระบบ PWA สมบูรณ์แบบ (PWA & Offline Readiness) — [สำเร็จ]
- **`frontend/src/app/manifest.ts`:** สร้าง App Router Manifest มาตรฐาน กำหนดสีธีม (`#1B2A24`), สีพื้นหลัง (`#FAF8F5`), และโหมด `standalone`
- **`frontend/public/icon.svg` & `icon-192.png` & `icon-512.png`:** สร้างไอคอนแอป WellTrip ขนาดมาตรฐาน
- **`frontend/public/sw.js`:** สร้าง Service Worker แคช Static Assets และรองรับ Offline Fallback
- **`frontend/src/components/pwa/pwa-install-banner.tsx`:** คอมโพเนนต์ดักจับ Event `beforeinstallprompt` (Android/Desktop) และแสดงคำแนะนำการติดตั้งสำหรับ iOS Safari
- **`frontend/src/app/layout.tsx`:** ติดตั้ง Meta Tags สำหรับ Apple Web App และแทรกคอมโพเนนต์ `PWAInstallBanner`

### 🟢 Stage 3: ยกระดับ GPS และความโปร่งใสของตำแหน่ง (Smart Location UX) — [สำเร็จ]
- **`frontend/src/lib/geo.ts`:** สร้างฟังก์ชัน `calculateDistanceKm()` และ `getDistanceToSisaket()`
- **`frontend/src/components/travel/LocationConsent.tsx`:** เมื่อผู้ใช้กดยอมรับพิกัด จะทำการคำนวณระยะทางจริง (เช่น จากพัทยาถึงศรีสะเกษ ~480 กม.) และแสดงข้อความตอบกลับที่ชัดเจน แก้ปัญหาความเข้าใจผิดว่าระบบเข้าใจว่าผู้ใช้อยู่ศรีสะเกษ

### 🟢 Stage 4: ตรวจสอบวงจรร้านค้า (Merchant Lifecycle Verification) — [สำเร็จ]
- ตรวจสอบ `MerchantRegisterSerializer` และ `register_merchant_view` รองรับข้อมูลครบถ้วน
- ตรวจสอบระบบ Admin Approval (`/admin/approvals`) สามารถกด Approve / Reject และอัปเดต `user.is_verified` ได้ถูกต้อง
- ตรวจสอบฟังก์ชัน Create/Patch ใน Vendor Portal สำหรับเพิ่มที่พักและสินค้า

### 🟢 Stage 5: การตรวจสอบคุณภาพและส่งมอบ (Verification & QA) — [สำเร็จ]
- **TypeScript Typecheck:** ผ่าน 100% (`npm run typecheck` — 0 errors)
- **Zero-Emoji Compliance:** ทุกคอมโพเนนต์ใหม่ใช้ไอคอนจาก `lucide-react` เท่านั้น
- **i18n Bilingual:** ข้อความใน PWA Banner และ GPS รองรับทั้งภาษาไทยและอังกฤษ
